Study of the principles, techniques, and tools for lexical, syntactic, and semantic analysis, as well as target code generation.

A compiler translates source code written in a programming language into semantically equivalent object code. In traditional toolchains, it translates high-level textual code into machine instructions tailored to a specific processor architecture and operating system.
