A disciplina de Desenvolvimento de Aplicações na Web (ODAW) aborda conceitos fundamentais da arquitetura web, capacitando estudantes a construir interfaces e serviços integrados a banco de dados.

A ementa abrange desde a estruturação estática de páginas até a programação dinâmica no servidor, cobrindo acessibilidade, usabilidade, design responsivo e segurança básica em aplicações web.

## Conteúdo programático

Tópicos práticos abordados no decorrer do semestre:

- [X] Introdução e evolução: fundamentos da Internet, histórico da Web e Internet das Coisas (IoT).
- [X] Estruturação e marcação (HTML e HTML5):
  - Listas, tabelas e formulários.
  - Elementos semânticos, mídias (áudio e vídeo) e desenho vetorial (Canvas e SVG).
- [X] Apresentação e estilo (CSS e CSS3):
  - Folhas de estilo externas, internas e inline.
  - Frameworks responsivos (Bootstrap, W3.CSS, Pure CSS).
  - Flexbox e CSS Grid.
- [X] Programação no cliente (JavaScript):
  - Manipulação de elementos do DOM e tratamento de eventos.
  - Validação de formulários com expressões regulares.
- [X] Programação no servidor (PHP):
  - Configuração de pilha LAMP/WAMP (Apache, PHP, MySQL).
  - Processamento de requisições GET e POST, sessões e cookies.
  - Fluxos de autenticação e criptografia de senhas.
- [ ] Integração com banco de dados relacional.
- [ ] Seminários de tecnologias emergentes, frameworks e arquiteturas.
- [ ] Projeto final: implementação de um sistema web completo.

## Exercícios práticos

A disciplina adota um modelo em que cada estudante define um tema central (como locadora de veículos, revenda automotiva ou catálogo de livros) e desenvolve um projeto cumulativo distribuído em dez entregas:

### 1. Estruturação básica com HTML

* Exercícios 1 a 3: criação da estrutura de páginas com textos, imagens e hiperlinks. Evolução para tabelas e formulários, finalizando com elementos semânticos do HTML5, áudio, vídeo e Canvas.

### 2. Estilização e layout com CSS

* Exercícios 4 a 6: organização de estilos com folhas externas e classes reutilizáveis. Construção de layouts responsivos com Flexbox, CSS Grid e frameworks utilitários como Bootstrap.

### 3. Manipulação do DOM e lógica com JavaScript

* Exercícios 7 e 8: manipulação dinâmica de elementos da árvore DOM, controle de eventos de formulário e validações no cliente por meio de expressões regulares.

### 4. Processamento no servidor com PHP

* Exercícios 9 e 10: configuração de scripts PHP, leitura e escrita em arquivos texto para contadores, controle de sessão via cookies e tratamento de submissões GET e POST com validação no backend.
